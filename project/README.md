## Description
This project is a Real Estate Website developed as my CS50 final project. The goal of the project is to create a modern and user-friendly platform where users can browse available properties and easily contact the company.

The website allows users to view property listings with detailed information such as price, location, and images. Each property is displayed in a clean and structured layout, making it easy for users to navigate and find what they are looking for.

A key feature of the website is the contact system. Users can send inquiries directly through the website, and there is also WhatsApp integration for faster communication. This improves user experience and makes communication more convenient.

The project also includes an admin system. The admin can add new properties, edit existing listings, and delete properties when necessary. This allows the website to stay updated without needing technical knowledge every time changes are required.

Another feature included is the Leadership Team section, which displays key members of the company along with their roles. This helps build trust and gives the website a more professional appearance.

Additionally, the website includes a Services section, which highlights services offered by the company, including LED advertising. This expands the functionality of the platform beyond just property listings.

The project was built using HTML, CSS, and JavaScript for the frontend design and interactivity. SQLite was used for storing and managing property data. These technologies were chosen because they are efficient, lightweight, and suitable for building a responsive web application.

One of the design decisions made was to keep the interface simple and clean. This ensures that users of all levels can easily navigate the website without confusion. The layout is also responsive, meaning it works well on both desktop and mobile devices.

In conclusion, this project demonstrates the ability to build a complete web application with both user-facing features and admin functionality. It solves a real-world problem by providing a digital platform for property listings and communication.

## Files

- index.html – Homepage of the website
- listings.html – Displays all properties
- property.html – Shows detailed property information
- add_property.html – Admin page to add new properties
- edit_property.html – Admin page to edit properties
- admin_properties.html – Admin dashboard for managing listings
- admin_messages.html – View user inquiries
- styles.css – Website styling
- database.db – SQLite database for storing data
