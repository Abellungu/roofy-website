## 不可破的红线 / Hard rules

1. **「正在拓展中」不是「已经做了很多」**
   LED 户外广告业务**还在搭建中**。文案保持 *"now booking founding partners / 正在拓展中、当前正接洽首批合作客户"* 的口吻。**绝不可以**写出「300+ 媒介点位」「覆盖全国」「行业领先」「成熟体系」这类自夸式数字或形容。

2. **公司创立于 2024 年**
   写「自 2018 年起」或任何「7+ 年经验」「320+ 套已交付」之类的虚假数字会被审查打回。把虚荣指标替换为真实强项：**3 大业务线 / 6 位领导 / 卢萨卡 Ibex Hill 总部**。

3. **不要编造客户证言**
   现在没有真实可用的客户故事，主页和业务页一律使用 *"Stories — coming soon / 故事正在书写中"* 的空状态。等真实客户授权后再启用。

4. **标语神圣**
   `Build, Brand, Grow with Roofy.` 是品牌官方 tagline，**不可以**简写、不可以拆开、不可以改成 "Build·Brand·Grow" 之外的中段连接符。中文版本只有：`筑造 · 塑造品牌 · 共同成长`。

5. **品牌标识使用规则**
   导航栏、页脚、Loader 一律使用 Cinzel 字体的 `ROO·FY` 文字标识（FY 部分金色渐变）。原始 `logo.jpg` 由于深蓝底色，**只用于** favicon / apple-touch-icon / og:image / JSON-LD schema 中。

6. **房源信息是「指示性内容」**
   所有房源标注、价格、面积、产权状态在网站上都是参考；最终以现场尽调与正式签约文件为准。这条法律口径要在新增 Listing 的描述里反映。

## 软规则 / Soft rules

- **中英对照** — 任何对外可见的字符串都必须中英双语。如果不会翻译，发回去给文案而不是发布单语版本。
- **诚实的表达 > 营销腔** — 写「我们以匠人之心雕琢居所与品牌」比「行业领先一站式服务商」更贴近 ROOFY 的形象。
- **图片宁少勿假** — 没有真实照片就用占位图（标记 `data-placeholder="true"`），不要用 Unsplash 的高大上图片冒充 ROOFY 自己的项目。
- **联系信息只有一个真值**：电话 `+260 964 813 736`、邮箱 `roofy@mingyangrt.com`、地址 `2742/M Second Street, Ibex Hill, Lusaka`。
